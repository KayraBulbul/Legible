# Accessibility layer

This context describes the user-owned reading snapshots and preferences managed by the accessibility layer.

## Language

**Saved page**:
A user-owned snapshot of a web page captured for later reading. It is historical content, not a live copy of the source page.
_Avoid_: Bookmark, live page

**Favourite**:
A user's marker on a saved page that identifies it for distinct presentation or quicker access.
_Avoid_: Favorite, starred page
